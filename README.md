# Porsche 911 Carrera RS 2.7

## Introduction
This project is a simple HTML and CSS webpage dedicated to the legendary Porsche 911 Carrera RS 2.7. It showcases the car's history, design, performance, and legacy with detailed descriptions and high-quality images.

---

## Features
- Responsive design using HTML and CSS
- A visually appealing background with a gradient effect
- Structured sections covering the introduction, design, engine, and legacy
- Image gallery with a horizontal scroll feature
- Smooth scroll-to-top functionality

---

## Technologies Used
- HTML5
- CSS3

---

## Installation
1. Clone this repository:
   ```sh
   git clone https://github.com/edwingeorgeshaji/Porsche-911-Carrera-Webpage.git
   ```
2. Navigate to the project directory:
   ```sh
   cd Porsche-911-Carrera-Webpage
   ```
3. Open `6th one css.html` in a web browser.

---

## Usage
Simply open the `6th one css.html` file in any modern web browser to explore the webpage. No additional setup is required.
